# Разработка

Основной код находится в `rust_clicker/src/`: `app.rs` — интерфейс, `hunter.rs` — захват и сессия поиска, `vision.rs` — распознавание, `engine.rs` — выполнение режимов, `win_input.rs` — Windows-ввод.

## Проверка

```powershell
./scripts/verify.ps1
```

Скрипт использует Cargo.lock и отдельный каталог сборки `%TEMP%\clicker-pro-target`. Это позволяет избежать проблем GNU linker с кириллицей в путях к объектным файлам. Сеть нужна для первоначального скачивания зависимостей; для уже заполненного Cargo cache можно передать `-Offline`.

Не запускайте тесты `screen_capture::tests::test_capture_screen` и `win_input::tests::test_find_roblox` на пользовательском рабочем столе без понимания их действий: второй может отправить ввод в игру. Скрипт исключает оба. Некоторые старые проверки используют локальные дополнительные кадры и пропускают их при отсутствии; основной регрессионный кадр поставляется в `tests/fixtures/`.

В релиз прикладываются `ClickerPro.exe`, ZIP с краткой инструкцией и `SHA256SUMS.txt`. Номер версии задаётся в `rust_clicker/Cargo.toml`; заголовок окна берёт его оттуда.
